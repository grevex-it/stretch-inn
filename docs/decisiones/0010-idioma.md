# 0010 — Idioma: español argentino

**Fecha:** 29/10/2026 · **Estado:** aceptada

## Decisión

- Código, nombres, comentarios, documentación e interfaz **en español**.
- La interfaz usa **voseo argentino** («Guardá», «Elegí la sede»).
- No se prepara la interfaz para varios idiomas.
- Fechas guardadas en `timestamptz` (UTC); se muestran en la zona horaria del centro.
